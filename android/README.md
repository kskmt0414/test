# MaxBright — 画面を最大輝度に固定するアプリ（root不要）

個人利用向けに、**root化なし**で画面を「到達可能な最大の明るさ」に固定し続ける Android アプリです。

---

## ⚠️ 最初に：技術的な限界について（正直な説明）

**root なしのアプリは、端末のハードウェア/OS の最大輝度を物理的に超えることはできません。**
バックライトを限界超過（オーバードライブ）させるには `/sys/class/backlight/...` や
`/sys/class/leds/...` への直接書き込みが必要で、これは **root 権限が必須**です。

このアプリが root なしで到達できる **本当の最大** は、次の組み合わせです:

1. **ウィンドウ輝度を 1.0（最大）に固定** — システムのスライダー設定に関係なく、
   アプリ表示中は常に最大。権限不要。
2. **画面スリープ防止**（`FLAG_KEEP_SCREEN_ON`）— 時間経過で暗くならない。
3. **システム輝度を 255・自動調整OFF**（`WRITE_SETTINGS` 許可時）— 効果をより強く・
   端末をまたいで安定させる。

### 「限界突破」に一番近い唯一の合法的な仕組み

多くの端末（Samsung / Pixel / Xiaomi など）では、ウィンドウ輝度を 1.0 に固定した状態で
**周囲が明るい**と、OS が自動的に **HBM（High Brightness Mode / 屋外・サンライトモード）** を
作動させ、**手動スライダーの最大値を超える**明るさになります。

アプリから HBM を**強制**することはできませんが、輝度を 1.0 に固定することでこの自動 HBM が
働きやすくなります。これが root なしで「限界突破」に最も近い挙動です。

## ビルド方法

このリポジトリの環境では Android SDK が使えないため APK は同梱していません。
お手元の PC（Android Studio か SDK）でビルドしてください。

### A. Android Studio（推奨・簡単）

1. Android Studio で `android/` フォルダを開く
2. Gradle Sync が終わるのを待つ（依存関係を自動ダウンロード）
3. 端末を USB 接続、または エミュレータを起動
4. ▶ Run を押す → インストールして起動

### B. コマンドライン

前提: `ANDROID_HOME`（または `ANDROID_SDK_ROOT`）が設定済みで、SDK Platform 34 と
build-tools が入っていること。初回は `local.properties` に SDK パスを書きます:

```
sdk.dir=/path/to/Android/Sdk
```

デバッグ APK をビルド:

```bash
cd android
./gradlew assembleDebug
```

生成物: `app/build/outputs/apk/debug/app-debug.apk`

端末に直接インストール（adb 接続時）:

```bash
./gradlew installDebug
```

## 使い方

1. アプリを起動すると自動的に最大輝度で固定されます。
2. 「システム輝度も上げる」ボタンを押すと権限設定画面が開きます。
   「MaxBright」の**設定の変更**を許可すると、システム輝度も 255 に上がります。
3. スイッチをオフにすると通常の輝度に戻ります（アプリ終了時も元に戻します）。

> 屋外モード（HBM）は、明るい場所で自動的に作動します（対応端末のみ）。

---

## 権限について

- `WRITE_SETTINGS`（設定の変更）: システム輝度を上げるためだけに使用します。
  通常のダイアログでは許可できない「特別な権限」なので、アプリが設定画面へ誘導します。
  この権限を許可しなくても、**ウィンドウ輝度の最大固定（主効果）は動作します。**

## 対応環境

- Android 5.0（API 21）以上
- コンパイル対象: API 34
- 言語: Kotlin
